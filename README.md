Financial Analytics Portfolio
This repository contains five data analytics projects demonstrating financial modeling, risk assessment and data manipulation using Python and machine learning.

Projects Included

1. Portfolio Optimization using Modern Portfolio Theory (MPT)

Objective: Construct an optimal asset portfolio to maximize returns while managing risk.

Techniques: Modern Portfolio Theory (MPT), Python (Pandas, NumPy).

Outcome: Achieved a simulated 27.63% return with a 0.91 Sharpe ratio.

2. Fraud Detection in Financial Transactions

Objective: Identify fraudulent financial transactions.

Techniques: Random Forest Classifier, SMOTE (Synthetic Minority Over-sampling Technique), balanced class weights.

Outcome: Engineered a pipeline that accurately flags fraudulent activity without overfitting to the majority class.

3. Time Series Analysis For Revenue Forecasting

Objective: Forecast future business revenue trends based on historical financial data.

Techniques: ARIMA Time Series Modeling, Python (Pandas, statsmodels).

Outcome: Built a predictive model to project future revenue streams, supporting financial planning and variance analysis.

4. Customer Segmentation For Financial Services

Objective: Group financial customers based on behavioral and transactional data for targeted strategies.

Techniques: K-Means Clustering, Data Preprocessing.

Outcome: Successfully segmented 1,000 records into 4 distinct customer clusters.

5. Credit Risk Analysis for Loan Approval

Objective: Predict loan defaults using financial indicators.

Techniques: Logistic Regression, balanced class weights to correct the Accuracy Paradox, StandardScaler.

Outcome: Successfully identified high-risk loans in a highly imbalanced dataset.

Technologies Used

Python (Pandas, NumPy, Matplotlib, statsmodels, Scikit-Learn, Imbalanced-Learn)
